# WINNER AUTO CLUB — Официальный сайт

Премиальный сервис подбора, технической экспертизы и доставки автомобилей из США и Европы в Грузию (Рустави / авторынок AUTOPAPA).

Сайт воссоздан с максимальной точностью по визуальному источнику правды (видеореференс 1280×720) и оптимизирован для десктопных и мобильных экранов.

## Особенности реализации

- **Editorial Минимализм:** Чередование контрастных тёмных секций (`#0d0d0f`) и тёплого оттенка слоновой кости (`#f6f4ee`), акцентный красный цвет (`#d43b36`), тонкие разделители и типографика Plus Jakarta Sans.
- **Интерактивный Hero Slider:** 3 слайда с рабочим скраббером/ползунком (`001 / 121`, `064 / 121`, `121 / 121`), кнопками перелистывания и индикаторами.
- **Каталог автомобилей:**
  - Живая фильтрация по категориям: *Все автомобили*, *Седаны*, *Спорткары*, *Кроссоверы*, *Электромобили*.
  - Поиск по марке, модели и параметрам в реальном времени.
  - Сортировка по цене, годам выпуска и максимальной выгоде.
  - Карточки с реальными фото, характеристиками и разницей с рынком Грузии.
- **О нас:** Редакционная панорама Porsche Panamera, ключевые показатели клуба (140+ параметров проверки, 100% фиксация бюджета, 7-14 дней на подбор).
- **Этапы работы:** Пошаговая колоночная структура (01 Знакомимся → 02 Сравниваем → 03 Планируем заказ → 04 Встречаемся).
- **Интерактивный Калькулятор выгоды:**
  - 6 реактивных параметров ($) с плавными слайдерами.
  - Двойная визуальная шкала сравнения: монолитная рыночная цена vs сегментированная стоимость через WINNER AUTO CLUB.
  - Мгновенный пересчет чистой экономии в долларах и процентах.
- **FAQ Аккордеон:** 6 развернутых ответов на ключевые вопросы по доставке, проверке Carfax, гарантиям, оплате и растаможке.
- **Локация и Контакты:** Прямые контакты в Рустави (Автопапа), номер `+995 511 299 299`, интерактивная карта с отметкой координат и ссылка на Google Maps.
- **Модальное окно заявки:** Интерактивная форма подбора с предзаполнением контекста (автомобиль из каталога или расчёт калькулятора).

## Стек технологий

- Чистый семантический HTML5
- Модульный CSS3 (CSS Variables, Flexbox, Grid, плавные анимации, 1280×720 pixel-perfect + Mobile Responsive)
- Нативный JavaScript (ES6+), без лишних зависимостей и библиотек
- Полная совместимость с GitHub Pages без необходимости сборки

## Запуск локально

Открыть `index.html` в любом современном браузере или запустить локальный сервер:

```bash
# Python
python -m http.server 8080

# или Node.js
npx serve .
```
